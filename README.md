# custom-rc-car-chassis
&#x09;

### RC Car Chassis for Custom RC Car

---
This is custom Car Chassis for RC bot, it features standard motor mount and curved front part for ball retention.

## Features
- Custom made
- Standard Motor Mount
- Central Cut for wiring
- Fits varies motor and tire sizes
- Curved front part for ball retention
